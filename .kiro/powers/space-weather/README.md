# Space Weather Kiro Power

Reusable Agent Plugin Power built for **Kiroween 2026 (Banshee)**.

## Capabilities
- Connects Kiro to live NOAA SWPC L1 solar wind (`SOLAR-1`, `ACE`, `IMAP`), NOAA GloTEC global ionosphere maps, Kp forecasts, and CelesTrak GNSS orbital elements via `swpc-mcp`.
- Loads `skills/space-weather-analysis.md` automatically on keywords: `solar wind`, `Kp`, `TEC`, `GNSS`, `GPS`, `ionosphere`, `space weather`.
